# TuniBless Member Dashboard

A front-end prototype of a member dashboard for TuniBless, a volunteer organization in Tunisia. The interface is in Arabic (right-to-left, dark theme).

## What it shows
- Member login screen (demo ID: `TB-0001`, simulated in the browser, no backend)
- Monthly stats: events attended, volunteer hours, attendance rate, total events
- Bar chart: events per month for the last 6 months
- Doughnut chart: volunteer hours by activity type
- List of recent events with attendance status (attended / absent)

## Tech
- HTML, CSS (flexbox and grid), JavaScript
- Chart.js 4.4 for the charts
- Responsive layout, right-to-left text

## My role
I designed and built the dashboard and tested it with the organization.

## Notes
This is a prototype with sample data. A production version would need a backend for member accounts and attendance records.

## Files
- `index.html`: entry page
- `tunibless_dark_dashboard.html`: dashboard page

## Run locally
Open `index.html` in a browser. Log in with `TB-0001`.
